# 安心导航 (AnXin Campus Navigation) 开发文档

## 1. 项目概述

**安心导航** 是一款基于 Java Swing 的桌面端校园智能路线规划系统。用户可以在校园地图上选择起点和终点，系统基于图论算法（Dijkstra / A*）自动计算最短路径并可视化展示；同时支持管理员对地图数据进行编辑维护（增删改地点/道路、设置禁行路段等）。

- **项目名称**: 安心导航 (AnXin Campus Navigation)
- **项目类型**: Java 桌面应用程序
- **运行环境**: JDK 8+
- **部署方式**: 本地 JAR 包运行，完全离线，无需网络连接
- **当前数据规模**: 44 个校园地点，涵盖教学楼、宿舍、食堂、图书馆、大门、办公室、运动场等

- 无 Spring / Spring Boot 框架
- 无数据库驱动（无 MySQL、SQLite 等）
- 无 ORM 框架（无 MyBatis、Hibernate 等）
- 无 JSON 第三方库（无 Jackson、Gson、Fastjson）
- 无 Web 服务器（无 Tomcat、Jetty 等）

```
│   Swing 界面: 视图面板 + 控制器 + 地图画布          │

├──────────────────────────────────────────────────┤

│   持久化: JSON 文件读写、数据备份恢复、历史记录      │

```

## 4. 核心功能模块

### 4.1 路径规划引擎

#### 算法实现

**Dijkstra 算法** (`DijkstraStrategy`)：
- 使用优先队列（最小堆）优化查找
- 时间复杂度 O((V+E) log V)
- 自动跳过禁行道路
- 支持单向/双向道路

**A\* 算法** (`AstarStrategy`)：
- 使用欧几里得距离作为启发式函数
- 支持可配置的启发式缩放因子（控制搜索范围与精度的平衡）
- 适用于大规模图的快速路径查找

#### 导航模式

- **步行模式**: 默认速度 75 m/min，适合行人导航
- **摆渡车模式**: 默认速度 300 m/min，适合校园公交路线
- **路径结果**: 包含总距离、预计时间、分段距离、逐步导航指引

### 4.2 地图编辑系统

- **地点管理**: 添加/修改/删除校园地点（教学楼、宿舍、食堂等）
- **道路管理**: 添加/修改/删除道路，支持单向/双向、道路类型（主干道/小路/楼梯）
- **禁行设置**: 临时禁行某条道路（如施工路段）
- **撤销/重做**: 基于命令模式的完整 Undo/Redo 机制
- **快照/回滚**: 操作失败时自动恢复图状态

### 4.3 地图可视化

- **2D 矢量渲染**: 基于 Java 2D `Graphics2D`，支持缩放、平移
- **交互式编辑**: 鼠标点击添加/移动/删除地点和道路
- **吸附引擎**: 编辑时自动吸附到附近顶点
- **路径高亮**: 规划路径在地图上以不同颜色/样式渲染
- **地点图标**: 不同地点类型使用不同颜色和图标标识

### 4.4 认证与权限

- **PBKDF2WithHmacSHA256 密码哈希**: 12 万次迭代 + 16 字节随机盐值 + 32 字节密钥
- **角色系统**: ADMIN（管理员，可编辑地图）/ USER（普通用户，仅查询）
- **登录速率限制**: 5 次失败后锁定 30 秒
- **默认账号**: `admin/admin123`（管理员）、`guest/guest123`（访客）

### 4.5 数据持久化

- **JSON 文件存储**: `vertex.json`（地点）、`edge.json`（道路）、`user.json`（用户）、`meta.json`（元数据）
- **自研 JSON 解析器**: 递归下降解析，零外部依赖
- **原子写入**: 先写临时文件，再原子移动，防止写入中断导致数据损坏
- **数据版本管理**: 当前 `DATA_VERSION=2`，支持数据迁移
- **备份/恢复**: 支持手动创建备份和从备份恢复
- **路径历史**: 自动记录最近 20 条查询历史

## 5. 算法详解

### 5.1 路径规划算法

#### Dijkstra 最短路径

```
输入: 校园图 G，起点 startId，终点 endId
输出: PathResult（路径顶点列表、总距离、分段信息）

1. 初始化: dist[start]=0, 其余顶点 dist=∞
2. 优先队列 PQ 插入 (start, 0)
3. 循环直到 PQ 为空:
   a. 取出 dist 最小的顶点 u
   b. 若 u 是终点，结束
   c. 遍历 u 的所有邻接边 (u→v, weight):
      - 若边被禁行，跳过
      - 若 dist[u] + weight < dist[v]:
        更新 dist[v]，记录前驱节点 prev[v]=u
        将 (v, dist[v]) 插入 PQ
4. 回溯 prev 数组构建路径
5. 计算分段距离和导航指引
```

#### A* 启发式搜索

```
与 Dijkstra 的区别:
- 优先队列排序依据: f(n) = g(n) + h(n)
  - g(n): 起点到 n 的实际距离（同 Dijkstra 的 dist）
  - h(n): n 到终点的启发式估计值（欧几里得距离 × 缩放因子）
- 启发式函数 h(n) 可接受（admissible），保证最优解
```

### 5.2 图连通性检测

使用 **DFS（深度优先搜索）** 遍历全图，找出所有连通分量：
- 若连通分量数 = 1，图是连通的
- 若连通分量数 > 1，报告所有孤立子图

### 5.3 PBKDF2 密码哈希

```
算法: PBKDF2WithHmacSHA256
参数:
  - 迭代次数: 120,000
  - 盐值长度: 16 字节（随机生成）
  - 密钥长度: 32 字节 (256 bit)
存储格式: pbkdf2$iterations$hexSalt$hexHash
```

## 6. 数据模型

### 6.1 顶点 (Vertex) - 校园地点

```json
{
  "id": "GATE_E",
  "name": "东门",
  "type": "GATE",
  "x": 100.5,
  "y": 200.3,
  "description": "校园东侧主入口"
}
```

### 6.2 边 (Edge) - 校园道路

```json
{
  "fromId": "GATE_E",
  "toId": "LIB",
  "weight": 220,
  "oneWay": false,
  "forbidden": false,
  "roadType": "MAIN_ROAD"
}
```

### 6.3 用户 (User)

```json
{
  "username": "admin",
  "passwordHash": "pbkdf2$120000$abcd1234...$ef5678...",
  "role": "ADMIN"
}
```

|------|-----|

| **RoadType** | MAIN_ROAD, PATH, STAIRS |
| **Role** | ADMIN, USER |
| **EditToolMode** | SELECT, ADD_VERTEX, ADD_EDGE, MOVE_VERTEX, DELETE_OBJECT |

## 7. 构建与部署

### 7.1 环境要求

- JDK 8 或更高版本
- Maven 3.x

```bash
# 编译打包
mvn clean package

# 运行测试
mvn test

# 跳过测试打包
mvn clean package -DskipTests
```

### 7.3 运行方式

```bash
# 方式一: 直接运行 JAR
java -jar target/campus-navigation-1.0.0.jar

# 方式二: Maven 运行
mvn exec:java -Dexec.mainClass="com.anxin.navigation.app.AppLauncher"

# 自定义数据目录
set ANXIN_DATA_DIR=D:\my-data
java -jar target/campus-navigation-1.0.0.jar
```

## 10. 总结

安心导航是一个设计精良的 Java 桌面应用，具有以下显著特点：

1. **极简依赖**: 仅 3 个第三方库，核心功能全部基于 JDK 内置能力实现
2. **算法驱动**: 实现了 Dijkstra 和 A* 两种经典图论算法
3. **分层清晰**: DDD 分层架构 + MVC 模式，职责明确
4. **安全可靠**: PBKDF2 密码哈希、原子写入、快照/回滚机制
5. **用户友好**: 交互式地图编辑、撤销/重做、路径历史记录
6. **完全离线**: 无需网络连接，数据本地存储
7. **测试完备**: 20 个测试类覆盖所有核心模块
